# Maintainer Launch Checklist

1. Choose an available GitHub organization/repository name; this package does not reserve one.
2. Create a **public** repository and upload these files, preserving directories.
3. **Choose a license before accepting code.** Consult contributors on the appropriate OSI-approved license; no license is included by default.
4. Adopt a Code of Conduct and clarify copyright/CLA or DCO policy before code contributions.
5. Enable GitHub Discussions and create the five categories listed in docs/DISCUSSIONS.md.
6. Publish the seven discussion starters; pin the welcome announcement.
7. Enable Issues; consider branch protections, two-factor authentication, and secret scanning.
8. Replace the placeholder in docs/LINKEDIN_LAUNCH.md with the actual repository URL.
9. Invite 5–10 prospective founding contributors personally, with clear voluntary-participation expectations.
10. Schedule a first public asynchronous discussion of scope, governance, licensing, and feasibility criteria.
11. Do not announce an operational network, compensation, investment opportunity, or validated pricing before evidence exists.
